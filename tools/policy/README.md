# Size policy

`check_policy.py` runs on every commit (`.pre-commit-config.yaml`) and over every tracked file in CI.

```
python3 tools/policy/check_policy.py                 # every tracked file
python3 tools/policy/check_policy.py path/to/file.go # just these
```

## Rules

- **A file is at most 300 lines**, outside the `exclude` list in `policy.json`.
- **No em dash anywhere**, excluded paths included: use a full stop, a comma or a colon. An en dash in a range such as `1–31` is fine.

## Skipped

- Paths in `policy.json` `exclude`: the illustration pipeline, lockfiles, the Xcode project, CLDR currency data, Markdown.
- Files with `Code generated by`, `@generated`, `DO NOT EDIT`, `Do not edit by hand` or `Generated from` in their first five lines.
