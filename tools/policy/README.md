# Size policy

`check_policy.py` checks every tracked file, on every commit through pre-commit and in CI.

## The rules

- **A file is at most 300 lines.** The paths in `policy.json` `exclude` have no cap: the illustration folder,
  lock files, the Xcode project, the CLDR currency data and Markdown.
- **No em dash anywhere**, excluded paths included. Use a full stop, a comma or a colon instead. The checker and
  its test are the only files that name it.
- **Generated files skip the line cap**: a file with `Code generated by`, `@generated`, `DO NOT EDIT`,
  `Do not edit by hand` or `Generated from` in its first five lines.

## Run it

Every tracked file:

```bash
python3 tools/policy/check_policy.py
```

Only some files:

```bash
python3 tools/policy/check_policy.py path/to/file.go
```
