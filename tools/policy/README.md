# Size policy

`check_policy.py` runs on every commit through pre-commit, and over every tracked file in CI.

## The rules

- **A file is at most 300 lines**, except the paths in `policy.json` `exclude`: the illustration folder, lock
  files, the Xcode project, the CLDR currency data and Markdown.
- **No em dash anywhere**, excluded paths included. Use a full stop, a comma or a colon instead.
- **Generated files are skipped**: a file with `Code generated by`, `@generated`, `DO NOT EDIT`,
  `Do not edit by hand` or `Generated from` in its first five lines.

## Run it

Every tracked file:

```bash
python3 tools/policy/check_policy.py
```

Only some files:

```bash
python3 tools/policy/check_policy.py path/to/file.go
```
